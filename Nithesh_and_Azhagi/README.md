# Love Story Website ❤️

This is a personalized, romantic experience built for Nithesh and Azhagi.

## How to Run:
1.  Ensure the following files are in this folder (`e:\Test\valentine-story`):
    -   `meet.jpg` (For Chapter 1)
    -   `icecream.mp4` (For Chapter 2)
    -   `moon.jpg` (For Chapter 4)
2.  Open `index.html` in your web browser (Chrome, Edge, or Firefox).
3.  Enjoy the story!

## Features:
-   **Chapter 1**: "The Day You Walked In" - Golden theme, floating sparks.
-   **Chapter 2**: "Virtual Ice Cream" - Pastel theme, video memory.
-   **Chapter 3**: "The Arrow" - Emotional rain theme.
-   **Chapter 4**: "The Moon" - Starry theme.
-   **Final Page**: Proposal with fireworks and a playful "No" button.
